# DataSense AI – Intelligent Data Analytics Platform

DataSense AI is a Python-based, no-code data analytics platform that helps users analyze CSV datasets through an easy-to-use Streamlit interface. It combines data cleaning, exploratory data analysis (EDA), machine learning, model comparison, and report generation in one application.

## Features

- **Dataset Upload:** Upload CSV files for analysis.
- **Data Cleaning:** Identify and handle missing values and duplicate records.
- **Exploratory Data Analysis (EDA):** Explore dataset structure, statistics, and visualizations.
- **Machine Learning:** Train models for classification and regression tasks.
- **Model Comparison:** Compare supported machine learning models using evaluation metrics.
- **Report Generation:** Generate downloadable analysis summaries and reports.

## Technology Stack

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Visualization:** Plotly
- **Machine Learning:** Scikit-learn

## Project Workflow

1. Upload a CSV dataset.
2. Inspect and clean the data.
3. Perform exploratory data analysis.
4. Select a target variable and train a suitable machine learning model.
5. Compare model performance.
6. Generate a report of the analysis.

## Installation and Setup

### Prerequisites
- Python 3.10 or a compatible version
- pip

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/sivanya-natarajan/Data-Sense-AI.git
   ```

2. Open the project folder:

   ```bash
   cd Data-Sense-AI
   ```

3. Install the required packages:

   ```bash
   pip install streamlit pandas numpy plotly scikit-learn
   ```

4. Run the application using the correct main Python file:

   ```bash
   streamlit run app.py
   ```

   Replace `app.py` with the actual entry-point filename if your project uses a different one.
